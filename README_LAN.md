# Руководство: Мультиплеер по локальной сети (LAN) и с разных устройств

## 🎮 Как играть с двух устройств (ПК + Ноутбук / 2 ПК)

### Шаг 1: Подключение к одной сети
- Оба компьютера должны быть подключены к **одному Wi-Fi роутеру** или соединены сетевым кабелем (LAN).
- *(Альтернатива при игре через интернет)*: Оба устройства подключены к одной виртуальной комнате **Radmin VPN** или **ZeroTier**.

---

### Шаг 2: Настройка Брандмауэра Windows (только на Хосте)
Windows по умолчанию может блокировать входящие сетевые пакеты для новых программ.
1. На компьютере-хосте найдите файл **`setup_firewall.bat`**.
2. Нажмите по нему правой кнопкой мыши -> **«Запуск от имени администратора»**.
3. Файл откроет входящие порты `7777` (геймплей) и `7778` (автопоиск).

---

### Шаг 3: Запуск Хоста (Компьютер 1)
1. Запустите **`run_host.bat`**.
2. В окне консоли и в лобби отобразится ваш локальный IP-адрес (например, `192.168.1.23`).
3. Игра автоматически перейдет в режим сервера и начнет передавать UDP-маяки в локальную сеть.

---

### Шаг 4: Подключение со второго устройства (Компьютер 2)
1. Скопируйте папку с игрой на второй компьютер (в ней уже лежит готовый портативный файл `godot.exe`, на втором ПК **ничего устанавливать не нужно**!).
2. Запустите **`run_client.bat`** (или `run_game.bat`).
3. В окне лобби посмотрите на блок **«СЕРВЕРЫ В ЛОКАЛЬНОЙ СЕТИ»**:
   - Сервер первого компьютера появится там автоматически!
   - Нажмите **[ПОДКЛЮЧИТЬСЯ]** напротив сервера.
4. Если автопоиск ограничен роутером:
   - В поле **«IP Сервера (LAN)»** введите IP хоста: `192.168.1.23`
   - Нажмите **[ПОДКЛЮЧИТЬСЯ]**.
5. Выберите сторону (Баал / Молох) и класс (Пиявка / Десантник).
   - **Смена класса в лобби**: Класс можно свободно менять в любой момент ожидания боя через кнопки `[ПИЯВКА]` / `[ДЕСАНТНИК]` или кнопку напротив своего позывного в списке игроков. Выбор синхронизируется между всеми игроками в реальном времени.

---

### Шаг 5: Старт боя
- На Компьютере-хосте появится второй игрок в списке «Игроки в лобби».
- Нажмите кнопку **[НАЧАТЬ МАТЧ]** — оба игрока мгновенно перейдут в бой!

---

## 🔪 Управление в бою
- **WASD**: Потайловое дискретное перемещение.
- **Q**: Переключение слотов (Слот 1: Основное оружие / Слот 2: Одноручное).
- **Слот 2**:
  - **ЛКМ**: Стрельба из пистолета (Tribunal / Sudan).
  - **ПКМ**: **Удар боевым ножом в ближнем бою** (Fatwa, 40 урона, оглушение врага, безлимит).
- **Esc** или кнопка **[В ЛОББИ]**: Открывает тактическое меню паузы с возможностью вернуться в лобби.
