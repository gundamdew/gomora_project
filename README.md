# Quake 3D: Project Gomora (Godot 4)

Полноценный 3D Арена-Шутер в духе классического **Quake** с сохранением первозданного сетевого кода, LAN-автопоиска и лобби.

---

## ⚡ Ключевые особенности 3D Quake-геймплея

1. **Полноценная 3D Арена (Gothic Sci-Fi Arena)**:
   - Многоуровневая архитектура: центральный двор, готические колонны, укрытия, верхние галереи и балконы (+4.5м и +8м).
   - **Джамп-пады (Jump Pads)**: 4 импульсные платформы по углам арены, запускающие игрока на верхние уровни со звуковым эффектом и мощным вертикальным ускорением!
   - 3D динамическое освещение, тени, объемный туман (Volumetric Fog) и сияние (Glow/Bloom) для лазеров, плазмы и взрывов.

2. **Культовая физика движения Quake**:
   - Быстрый отклик управления и высокая скорость бега.
   - **Quake Air Strafe (Воздушный стрейф)**: ускорение в воздухе при повороте мыши с зажатым направлением.
   - **Рокет-джамп (Rocket Jump)**: выстрел из рокетницы в пол во время прыжка сообщает мощный 3D-импульс отдачи, забрасывая игрока на десятки метров вверх и через всю карту (с пониженным уроном по себе)!
   - Захват курсора мыши (`MOUSE_MODE_CAPTURED`) для плавного 3D-прицеливания по вертикали и горизонтали.

3. **Арсенал Quake с процедурными 3D-визуалами от первого лица (Viewmodels)**:
   - **[1] Клинок / Пила (Gauntlet)**: сокрушительное оружие ближнего боя с высоким темпом ударов.
   - **[2] Двуствольный Дробовик (Super Shotgun)**: залп из 10 картечин конусом с индивидуальными 3D-трассерами и тяжелым уроном в упор.
   - **[3] Пулемет (Machinegun)**: скорострельный непрерывный огонь со вспышками и трассерами.
   - **[4] Рокетница (Rocket Launcher)**: запуск 3D-снарядов с дымовым следом, объемными сферическими взрывами, AoE-сплэшем и физическим отбрасыванием.
   - **[5] Рельсотрон (Railgun)**: мгновенный снайперский луч через всю карту с легендарным сияющим спиральным следом Quake и уроном 100 (200 при хедшоте).
   - **[6] Плазмоган (Plasma Gun)**: скорострельные светящиеся энергозаряды.
   - Процедурные анимации оружия: покачивание при ходьбе (Bobbing), отдача (Recoil kick) и динамические 3D вспышки выстрела.

4. **3D Боты (Quake AI)**:
   - Боты симулируются на стороне хоста/сервера и передают координаты клиентам по сети.
   - Ведут позиционную борьбу, маневрируют и стрейфятся влево-вправо, уворачиваясь от ракет.
   - Выбирают дальнобойное оружие на дистанции (Рельсотрон/Пулемет) и Дробовик/Рокетницу вблизи.
   - Пользуются джамп-падами и захватывают контрольные секторы.

5. **3D Модели персонажей и хедшоты**:
   - Роботизированные гладиаторы в цветах команд: Баал (Красные) и Молох (Синие).
   - Отдельный хитбокс головы с множителем урона `2.0x` и звуком попадания в голову (Headshot Ding).
   - 3D-таблички позывных и полоски здоровья над головами.
   - Эффект гибели: разлет механических осколков и гибов с физикой твердых тел (RigidBody3D).

6. **Секторы и Цели матча (Режим захвата)**:
   - **Сектор A (Двор)**, **Сектор B (Центральная Башня)**, **Сектор C (Бастион)**.
   - Каждый сектор снабжен 3D-голографическим вертикальным лучом света, концентрическими вращающимися кольцами и плавающим статусом.
   - Захват каждого сектора начисляет +60 секунд бонусного времени.

## 🌐 Сохраненный в первозданном виде сетевой код (Multiplayer)

Сетевая архитектура полностью сохранена и работает в 3D:
1. **Автопоиск в локальной сети (LAN Auto-Discovery)**:
   - UDP-маяки на порт 7778 с автоматическим отображением серверов в лобби в реальном времени.
2. **Поддержка любых сетей**:
   - Локальная сеть (Ethernet/Wi-Fi), VPN (Radmin VPN `26.x.x.x`), Loopback (`127.0.0.1`).
   - Кнопка «СКОПИРОВАТЬ IP» в лобби для быстрой передачи напарнику.
3. **Выбор команд и классов в лобби**:
   - Армия Баала (Красные) vs Армия Молоха (Синие).
   - Классы (Пиявка, Десантник, Раптор, Авгур) со своими бонусами скорости и запаса брони/здоровья.
   - Одиночная игра против ботов («Одиночная игра») без необходимости в сети.
4. **Синхронизация матча**:
   - 3D-позиции игроков, углы обзора (Yaw/Pitch), выбранное оружие.
   - Выстрелы хитскана, полет ракет, взрывы и отбрасывание.
   - Синхронизация состояний ботов, таймера раунда и прогресса секторов.

## ⌨️ Управление

| Клавиша / Кнопка | Действие |
|---|---|
| **W, A, S, D** | Перемещение (Quake скорость и стрейф) |
| **Мышь** | Обзор в 3D (захват курсора по клику) |
| **Пробел (Space)** | Прыжок / Баннихоп |
| **ЛКМ (LMB)** | Стрельба активным оружием |
| **ПКМ (RMB)** | Снайперский зум (Zoom FOV) |
| **1 .. 6** | Быстрый выбор оружия (Клинок, Дробовик, Пулемет, Рокетница, Рельсотрон, Плазма) |
| **Колесо мыши** | Переключение оружия вверх / вниз |
| **Q** | Предыдущее оружие |
| **ЛКМ в пол + Пробел** | **Рокет-джамп (Rocket Jump)** |
| **Tab** | Таблица счета и фрагов команд |
| **Esc** | Меню паузы (освободить курсор, продолжить бой или выйти в лобби) |

## 🚀 Скрипты запуска

- **`run_game.bat`** — Запуск игры.
- **`run_host.bat`** — Автоматический старт хоста в локальной сети с выводом IP-адресов.
- **`run_client.bat`** — Подключение клиентом к серверу.
- **`run_lan_test_2_players.bat`** — Запуск двух клиентов на одном ПК для мгновенной проверки мультиплеера.
- **`setup_firewall.bat`** — Открытие портов UDP 7777 и 7778 в Windows Firewall (запуск от Администратора).
