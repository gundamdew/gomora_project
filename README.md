# Project Solomon — 2D Top-Down Shooter (Godot 4)

Тактический командный 2D шутер с видом сверху по дизайн-документу **Project Solomon**.

## 🎮 Ключевые параметры мира, камеры и движения
- **Размер тайла**: `32x32` пикселя.
- **Размер карты**: `100x100` тайлов (`3200x3200` пикселей).
- **Поле зрения (Vision)**: Ровно `15x15` тайлов (`480x480` пикселей) с пиксель-перфектным отображением и целочисленным масштабированием (окно 960x960, 2x).
- **Положение игрока**: Строго в центре квадрата зрения.
- **Потайловое движение**:
  - Перемещение происходит дискретно по сетке тайлов со сглаженной интерполяцией между клетками.
  - Скорость регулируется параметром **Задержка движения (Move Delay)** из диздока:
    - Пиявка (Leech): задержка `6` (эквивалент спринта на Ашане, шаг ~0.20с).
    - Десантник (Trooper): задержка `8` (эквивалент ходьбы на Ашане, шаг ~0.26с).
    - При получении оглушения (hit stun) задержка временно увеличивается на `+3` у легких и `+2` у средних классов.
    - Повреждение ног добавляет штраф к задержке (хромота `+3`, ползание при 0% `+8`).
    - Перекат (Dodge Roll) у Пиявки быстро преодолевает `3` тайла по сетке с кадрами неуязвимости.

## ⚔️ Режим игры и Команды
- **Красная команда (Армия Баала)**: Нападающие. Цель — последовательно захватить 3 сектора (Зона A -> Зона B -> Зона C) до окончания таймера раунда. При захвате каждой зоны к таймеру добавляется **+60 секунд бонусного времени**.
- **Синяя команда (Армия Молоха)**: Обороняющиеся. Цель — удержать сектора и не позволить нападающим захватить финальную базу до истечения таймера.
- **Система подкреплений (Волны)**:
  - **Волна 1**: Стартовая волна легких классов (**Пиявка / Leech**).
  - **Волна 2**: При накоплении потерь открываются средние классы (**Десантник / Trooper**).
  - **Волна 3**: Полномасштабный бой со всеми классами.

## 🩸 Система повреждений и Прочность (Integrity)
Каждый юнит имеет раздельные пулы прочности по частям тела:
1. **Туловище (Torso)**:
   - При обнулении Прочности туловища юнит **не погибает мгновенно**: включается **Камикадзе-режим (5 секунд)**!
   - Во время отсчета игрок **сохраняет полный контроль и подвижность**, что позволяет ворваться во вражеские ряды перед детонацией.
   - Через 5 секунд юнит детонирует, нанося мощный АоЕ-урон:
     - Легкие: 50 урона (Радиус 1 тайл)
     - Средние: 100 урона (Радиус 2 тайла)
     - Тяжелые: 250 урона (Радиус 3 тайла)
   - **Хедшоты**: Если атака, обнулившая туловище, попала в голову (или при попадании в голову активному камикадзе), юнит **моментально ликвидируется без взрыва**, игрок теряет контроль!
2. **Руки (Arms)**:
   - **Порог 50%**: При падении до 50% юнит теряет одну руку и больше **не может использовать двуручное оружие** (Слот 1 блокируется, автоматически переключается на Слот 2).
   - **Правило защиты порога (Gating)**: Если прочность рук выше 50%, ни одна стандартная атака не может опустить прочность ниже 50% за один выстрел (избыточный урон срезается, давая шанс).
   - **Порог 0%**: Теряются обе руки — стрелять невозможно. Доступна ручная активация камикадзе-режима по клавише `[E]`.
3. **Ноги (Legs)**:
   - При повреждении ног ниже 50% скорость снижается (хромает).
   - При 0% юнит падает и передвигается со скоростью ползания (-65% скорости).

## 🎯 Прицеливание по зонам (Кукла на интерфейсе)
На интерфейсе доступен выбор зоны стрельбы:
- **[1] ГОЛОВА**: Множитель урона `х1.5` по легким, `х1.35` по средним. Точный хедшот нейтрализует камикадзе.
- **[2] РУКИ**: Выводит из строя руки и блокирует двуручное оружие.
- **[3] НОГИ**: Замедляет и обездвиживает врага.
- Прямой клик по врагу наносит урон в выбранную зону. Случайные/трассерные попадания без прямого клика приходятся в туловище.

## 📏 Эффективная дистанция и АоЕ Fall-off
- **Эффективная дистанция**:
  - В упор: 2 тайла (64 px)
  - Ближняя: 4 тайла (128 px)
  - Средняя: 6 тайлов (192 px)
  - Дальняя: 8 тайлов (256 px)
  - Снайперская: 10 тайлов (320 px)
  - Внутри радиуса — 100% урон. За пределами — плавный спад до 70% на дистанции 2х.
  - Полупрозрачное зеленое кольцо радиуса вокруг персонажа переключается клавишей `[T]`.
- **АоЕ урон**:
  - В эпицентре и соседних тайлах — 100% урон, на границе радиуса — 30%.
  - АоЕ наносит 100% урона в туловище и по 30% в руки и ноги.
  - АоЕ и удары ближнего боя вызывают **Оглушение (Hit Stun / замедление)** длительностью `(Урон / Макс_ХП_Торса) * 5` сек.

## 🔫 Классы и Оружие
1. **Пиявка (Leech)** — Легкий класс:
   - Прочность: Торс 100 / Руки 60 / Ноги 60. Высокая скорость.
   - **Перекат (Dodge Roll)** на `[Пробел]`.
   - **Слот 1**: Винтовка Mk.Ultra (Двуручное, урон 15, магазин 30, темп 0.2с, средняя дистанция, автоогонь).
   - **Слот 2**: Пистолет Tribunal (ЛКМ, урон 10, магазин 8) + **Боевой нож Fatwa** (ПКМ, урон 40 в ближнем бою, оглушение, безлимит).
2. **Десантник (Trooper)** — Средний класс:
   - Прочность: Торс 200 / Руки 150 / Ноги 100.
   - **Слот 1**: Карабин Wagner (Двуручное, урон 30 (40 по легким), ПКМ — переключение АоЕ режима).
   - **Слот 2**: Комбо — Пистолет Sudan (ЛКМ, урон 20, магазин 6) + **Боевой нож Fatwa** (ПКМ, урон 40 в ближнем бою, оглушение, безлимит).

## ⌨️ Управление
| Клавиша | Действие |
|---|---|
| **W, A, S, D** | Перемещение по тайлам |
| **ЛКМ (LMB)** | Стрельба / Основная атака |
| **ПКМ (RMB)** | **Слот 1**: спецрежим Wagner / **Слот 2**: Удар ножом в ближнем бою (Fatwa) |
| **R** | Перезарядка (сбрасывает оставшиеся патроны в магазине) |
| **Q** | Переключение слотов оружия (Слот 1 / Слот 2) |
| **Пробел (Space)** | Перекат / Уклонение (для легкого класса) |
| **1, 2, 3** | Выбор зоны попадания (1 - Голова, 2 - Руки, 3 - Ноги) |
| **T** | Переключение отображения кольца эффективной дальности |
| **E** | Ручной подрыв Камикадзе (если обе руки уничтожены) |
| **Esc** | Открыть тактическое меню паузы (продолжить бой / выйти в лобби) |

## 🌐 Мультиплеер, Локальная сеть (LAN) и Автопоиск
В игру добавлено полноценное сетевое лобби на базе `ENetMultiplayerPeer` и UDP-автопоиска движка Godot 4:
1. **Реальный запуск локального хоста для игры с других устройств**:
   - Запустите **`run_host.bat`** на основном ПК.
   - Скрипт покажет ваш реальный IP в локальной сети (`192.168.1.23`) и в Radmin VPN (`26.202.103.67`), и запустит сервер с автовещанием в LAN.
   - Если другое устройство не может подключиться, запустите от администратора **`setup_firewall.bat`**, чтобы открыть входящие UDP порты 7777 и 7778 в Брандмауэре Windows.
2. **Подключение с другого устройства (ПК/Ноутбук)**:
   - Скопируйте папку с игрой на второе устройство и запустите **`run_client.bat`** (или `run_game.bat`).
   - Сервер появится автоматически в списке **«СЕРВЕРЫ В ЛОКАЛЬНОЙ СЕТИ»** — нажмите **[ПОДКЛЮЧИТЬСЯ]**.
   - Также можно ввести IP вручную и нажать `[ПОДКЛЮЧИТЬСЯ]`.
3. **Автопоиск в локальной сети (LAN Auto-Discovery)**:
   - Хост транслирует UDP-маяки как на широковещательный адрес `255.255.255.255`, так и на направленный subnet broadcast (например, `192.168.1.255`), обеспечивая надежное обнаружение через любые Wi-Fi роутеры.
4. **Выход в лобби во время игры**:
   - Клавиша **`[Esc]`** открывает меню паузы с кнопками «Продолжить» и **«Выйти в лобби»**.
   - Также в правом верхнем углу интерфейса доступна быстрая кнопка **[В ЛОББИ]**.
5. **Автореспавн при гибели**:
   - После гибели (или взрыва камикадзе) запускается 3-секундный таймер с оверлеем отсчета.
   - Игрок возрождается на базе своей команды со 100% здоровьем всех зон и пополненным боезапасом.
6. **Смена класса прямо в лобби**:
   - Находясь в лобби (до или после создания сервера/подключения), можно в любой момент переключить класс (Пиявка / Десантник).
   - Доступны быстрые кнопки `[ПИЯВКА]` / `[ДЕСАНТНИК]`, кнопка смены напротив позывного в списке игроков и стандартный выпадающий список.
   - Выбор мгновенно синхронизируется между всеми участниками по сети, а при старте матча игрок спавнится выбранным классом.

## 🎨 Текстуры, Тайлы (Turfs) и DMI-спрайты классов
1. **DMI-спрайты классов и предметов (`classes (3).dmi`)**:
   - Реализован встроенный парсер формата BYOND DMI ([dmi_parser.gd](file:///d:/gavno11/scripts/dmi_parser.gd) и [dmi_manager.gd](file:///d:/gavno11/scripts/dmi_manager.gd)), на лету извлекающий метаданные состояний, анимации и направления из PNG-чанков.
   - **Многослойность (Layering)**:
     - **Нижний слой (База)**: `класс_цифра` (например, `leech_0`, `trooper_1`).
     - **Верхний слой (Оверлей)**: `класс_оружие_рука` (например, `leech_mk_ultra_arms`, `trooper_wagner_arms`).
   - **Анимация при передвижении**: Во время шага (`is_stepping` / `is_rolling`) воспроизводится циклическая анимация ходьбы из DMI. В состоянии покоя юнит замирает на кадре 0.
   - **Механика отстрела рук**: При обнулении прочности рук (`arms_hp <= 0.0`) оверлей рук и оружия мгновенно удаляется (скрывается), визуально отображая потерю конечностей. При возрождении оверлей восстанавливается.
   - **4-направленный вижен**: Поворот персонажа отображается аутентичными 4-направленными спрайтами (Юг, Север, Восток, Запад) по направлению прицела мыши.
2. **Тайлы пола (Turfs)**:
   - В игру интегрированы текстуры тайлов пола из папки `turfs_solomon` (`tile1.png` — `tile6.png`).
   - Генератор карты ([map_generator.gd](file:///d:/gavno11/scripts/map_generator.gd)) детерминированно рандомизирует тайлы пола по координатной хэш-функции, гарантируя абсолютно одинаковый визуальный узор на 10 000 тайлах как у хоста, так и у клиентов.

## 🚀 Скрипты запуска
- **`run_host.bat`** — Запуск локального сервера (хост) для игры с других компьютеров в сети с выводом IP и автонастройкой.
- **`run_client.bat`** — Запуск клиента для подключения со второго компьютера к хосту.
- **`setup_firewall.bat`** — Однокликовое открытие портов 7777 и 7778 в Брандмауэре Windows (запускать от имени Администратора).
- **`run_game.bat`** — Стандартный запуск игры в оконном режиме.
- **`run_lan_test_2_players.bat`** — Тест мультиплеера на 1 ПК (запуск 2 синхронизированных окон: Хост и Клиент).
